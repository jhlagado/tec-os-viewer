# Ownership, price and complete interval

The normal process roles are outer Python, GNU timeout, shared guard Node,
one entry/adapter Node and at most one serial synchronous guard query. The
entry denies child permission before importing the adapter. Its closed imports
contain no child/Worker API, compiler, browser or SDK. The derived data URL
imports only builtin crypto. Threads remain in each process's RSS.

Retain actual LP64 subreaper SET/GET, the original Popen handle, sole WNOWAIT
identity then specific consuming wait4 and actual ECHILD. Numeric signal
authority ends before consumption and cannot revive. No Popen poll/wait,
PID-name cleanup, outer group kill, sampler or new guardian is added. Unknown
ownership stays held/reap-only. Any adopted/extra/lost/unknown/held status or
latched signal prevents the normal price.

T is the actual specific Linux timeout-wait highwater, propagating normally
reaped descendant maxima. O is final outer SELF after complete source/provider,
raw capture, output, semantic and parent checks, file/parent fsync and EOF/hash.
The normal conservative sum is O+4T+8,388,608 <= 629,145,600 bytes. Maximum with
the separately retained sequential original DATA preflight peak must fit the
same ceiling. No aggregate CHILDREN subtraction, old M0 measurement or guard
sample replaces this job's actual price. Heap64 is not total RSS.

The work root is created exclusively 0700 before Popen, with its opened device,
inode, mode and ownership retained. Existing parent identities are exact and
canonical. JavaScript uses bigint stat and decimal strings for those values.
Normal output is three regular single-link 0600 files: context.dat <=8192,
result.dat <=65536 and ended.dat <=4096. The only extra first-failure name is
failed.dat <=16384. There are no nested directories or unbound output names.
Absent, empty or partial files stay actual first outcomes, never replacements.

The adapter and entry use checked complete nonempty O_SYNC/wx writes and close
in finally. Node does not call fsync under --permission. After actual wait the
Python owner flushes/closes its owned raw capture FDs, then audits reopened
regular files without following links. Stable device/inode/mode/link/size/mtime/
ctime joins surround actual EOF/hash/fsync. The work directory, which is the
adapter capture's parent, is fsynced through the retained plain directory FD.
All normal source/package/runtime/parent postflight and full literal checks
finish before SELF and the work FD closes before that sample.

The normal aggregate is fully fixed independent DATA: eleven ordered rows,
complete HTML/text/refusal/mutant fields and 12,691 expected encoded bytes.
Both byte equality and parsed equality are required. Context's actual argv,
environment, child denial, parent, source and generated URL join the owner.
ended.dat attests only import return and postflight, not interpreter shutdown
or parent fsync. Actual terminal, guard rows, exact sole wait/ECHILD and raw
marker are separate mandatory joins. Early markers cannot qualify a job.

On a known-ended failure, bounded partial work/raw audits are attempted while
their actual identities remain retained. Audit errors stay explicit errors.
Their snapshots do not turn lost status or an unknown writer into normal EOF
or resource evidence. Unknown/live ownership remains with the sole waiter and
can exceed timing limits without cleanup/price/extinction credit. Every actual
partial path and raw diagnostic must be retained outside before any successor.

The original monotonic outer sample follows import time and precedes all other
imports, source loading and work. It is never reset: 118 seconds overall and
five seconds through prelaunch. Timeout remains TERM112 seconds plus one before
KILL. A genuine root header supplies the original same-host monotonic entry
before Python startup; the owner additionally checks that containing 120-second
interval through its tail. Root separately retains the continuous external
tool interval from original preflight to actual terminal/capture/receipt closure.
These are distinct observations, not a selected tool-wall sum or a physical
cutoff/suspension guarantee. Original host/boot context must match.

After normal SELF only scalar price/receipt/summary/clock work remains. The
final receipt is capped 64 KiB, created exclusively with an explicit 0600 FD,
fully written/fsynced/closed. Its bounded tail uses the unchanged 8 MiB reserve.
No normal source hash, output read, tree walk or archive runs after SELF. The
outside receipt parent retains the old M0 limitation: it is not the worker-
directory audit. Capture-parent fsync is fully required before SELF. Neither
path proves physical-media/power-loss retention. Final late signals or either
original deadline override any earlier normal-looking receipt.

Raw stdout/stderr each have a 4 MiB normal cap and guard log 64 KiB. Exceeding
a cap fails normal qualification but preserves actual files and raw failure.
Root retains the complete source/provider/authority/command/tool history and
all actual outputs, including partials, in a separately read-back offline
archive/index. Offline packaging is not a hidden concurrent role or a fit claim.
Source remains inactive; no actual, runtime capability, measured fit, resource
