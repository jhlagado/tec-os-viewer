# Command price and retention

Five roles bound the proposed normal command: outer Python, GNU timeout,
shared guard Node, the child-denied M0 Node and one synchronous guard query.
The model imports only Node crypto. The driver imports filesystem, path,
URL and crypto builtins before its child-denial check. It imports the model
after source validation and staging. Neither file imports product code,
a compiler, a browser, worker threads or a child-process API.

The launcher retains the qualified comparator's sole WNOWAIT and specific
wait4 mechanism. Popen stays globally referenced and has no competing poll
or wait. Numeric signal authority ends before consuming the anchored direct
child. Actual raw zero, a pre-reap zombie identity, empty zombie argv,
exactly one direct wait and final ECHILD are required. Adopted children,
lost status, signals and holds prevent normal price credit. Exceptional
ownership remains with the same waiter, even beyond the timing limit.

The specific Linux timeout wait maximum T bounds each of the four descendant
roles in that exact normal topology. Outer SELF O is sampled after all source,
provider, output and capture reads, joins and hashes. The conservative price is:

    O + 4*T + 8*1024*1024 <= 600*1024*1024

SELF is a maxRSS scalar with its full raw rusage fields. The specific wait
retains raw status, exact PID, pre-reap identity and raw rusage fields.
Inherited aggregate CHILDREN is not subtracted or used as this job's price.
Heap64 limits Node old space, not RSS or Buffer allocations. The guard's
sampled 600 MiB Linux RSS check is separate from the complete actor price.

The finite normal output set is S+45 files, where S is the sealed source-file
count including offer.dat. This comprises S source copies, 34 case readings,
six notice files, depnew.dat, readings.dat, inputs.dat, result.dat and files.dat.
Each source file and the altered dependency descriptor is at most 2 MiB.
Case readings are at most 16 KiB each,
notice files 8 KiB each, aggregate readings 256 KiB, identities 128 KiB,
result 16 KiB and inventory 128 KiB. The first-failure file is capped at
32 KiB and prevents a normal result. Full stdout and stderr each have a
4 MiB normal cap. The complete guard log has a 64 KiB normal cap. Exceeding
a cap retains the actual output and fails the normal candidate.

Actual positive descriptor/file/root/package/lock joins use streamed provider
hashes with a single reusable 64 KiB block. They occur before the contrasts and
again at finalisation. Full Viewer baseline blob hashes are also checked.
These are setup/postflight checks. A failure there is not semantic refusal
credit. The named declared-row contrast alone is passed to the pure model.

All model allocations, source copies, per-case results, output hashes and
Node finalisation occur before its exit, within T. The outer checks the exact
output set and every inventory row, then independently joins all 34 readings
to fixed case and literal-oracle data. It validates the complete altered
dependency descriptor, both named row values, positive actual file-join summaries
and all six notice files,
staged source bytes, the actual command/environment and false scope flags.
All of that precedes O. After O, the normal path only assembles bounded
scalar metadata and the final receipt, exclusively writes and fsyncs at
most 64 KiB, prints a small summary and samples the clock. The unchanged
8 MiB reserve covers this final tail. No source hash, tree walk or output
read belongs after O.

Captures are regular files, not pipes. Their owned FDs are set to 0600 before
Popen. They close and fsync after the actual wait chain and final ECHILD.
The outer then reopens each capture and guard log without following links,
checks its stable inode, mode, link count and size, fsyncs and reads through
actual regular-file EOF while hashing. The guard log inherits child umask077.
The sealed normal source contains no detached writer or extra actor. This
end-of-writer account does not claim a separate pipe EOF observation.

The driver opens each nonempty exclusive output with the public wx flag bits
plus O_SYNC and checks every positive writeSync result through full completion.
It closes the FD in finally. This preserves the permission model and child
denial. JSON plus LF and all finite source/notice bytes are nonempty. The old
unsupported fsyncSync path is absent. Node source completion is not an outer
post-wait durability receipt.

After actual wait, the outer audits at most 72 declared files and four nested
private directories. The normal set stays 71 files. The extra allowed name is
the bounded failed.dat and it cannot satisfy the normal exact-set validator.
Existing partial or empty files can be flushed and retained by this audit.
Each opened file must match its lstat device, inode, mode, link count, size,
mtime and ctime before and after fsync and actual EOF/hash. Bottom-up directory
fsync uses exact opened identities. All file, guard and directory audits finish
before SELF. Audit failure retains the actual files but supplies no completed
audit or normal price. Unknown or held endings retain their existing ownership
rules and cannot enter the normal price path.

The final receipt's exclusive owned FD is set to 0600 before its bounded write,
flush, fsync and close. Its parent directory is outside the evidence-directory
audit. The 8 MiB final-tail reserve and 64 KiB receipt cap remain unchanged.
No file operation here establishes physical-media or power-loss durability.

The outer samples its 118-second deadline immediately after importing time.
Python startup and that import precede this local sample. GNU timeout allows
112 seconds with one second before KILL. The five-second prelaunch reserve
is charged to the outer interval. Root must separately retain a continuous
external observation from before env/Python startup through actual terminal,
capture closure and the receipt tail, within 120 seconds. No physical cutoff
or suspension guarantee follows from an alarm or a normal-looking early
receipt. A late signal or deadline overrides the normal candidate. Historical
700/450 plans and Mac thresholds remain unchanged.

Root retains the exact allocation and original pre-start runtime observation,
full invocation and responses, all raw captures and actual outputs including
failure artifacts. The original 1022-file runtime, five links, four absences
and scoped standard library sets must be checked before Python startup and
again by the outer. The source offer is inactive and supplies no actual host
observation, price, child-denial result or release decision.
