TEC-OS on an emulated TEC-1G built from tec-os-viewer ed1bb10 and tec-os 8a7e24e

Columns and Display restart the machine, restore the card's default drives, and may update startup configuration. Reset keeps selected directories where possible; Power cycle restores defaults. These actions discard pending guest RAM writes.

Click the screen to type on the matrix keyboard; on a phone, tap it to bring up the keyboard. The serial terminal is the console after CON TTY; CON CRT or CON UC1 comes back.

Guest cache, card image and browser storage are separate stages.
          A browser save or Download image includes card bytes, excluding pending guest data
          and an application's unclosed buffers or file metadata. Browser storage can fail or be cleared.

        

          
          
          
        

        
Copy unavailable during startup.

        
Copy as applies to Copy file to drive and to Download.
          With "text or binary, by file", a file whose bytes are all text goes on the card as text, with CRLF
          line ends and a ^Z at the end, and comes off with LF line ends and no ^Z; .COM, .SVC, .RTL, .BIN and
          any file with other bytes are copied as they are. "text" and "binary, as it is" force one or the other.

        
UserNameBytes

        
Copy file stages the selected files, saves the changed card when browser saving is
          available, then resets the TEC-1G. That reset can discard pending guest RAM writes and unclosed
          application work; browser saving includes card bytes only.
          Open image and New starter card replace the card and restart.

        
Recover the shell after changing A's directory
          
At the bare prompt, list directories and restore SYSTEM, select user area 0,
            then load the shell. CD changes the directory presented by a drive.

          
A>CD ?
A>CD A:SYSTEM
A>USER 0
A>SHELL.SVC

          
Reset can retain A's selected directory. Power cycle restores the card's defaults.
            Neither action flushes pending guest RAM writes first.
